# Issues

Linear처럼 프로젝트와 이슈를 관리하고, 이슈 내용으로 Orca 작업을 실행하는 사이드바 패널입니다.

## 기능

사용법과 화면 캡처는 **[매뉴얼](docs/manual.html)**에 있습니다. 패널 왼쪽 아래 `📖 매뉴얼` 버튼을 누르면 다운로드 폴더의 `issue-tabs` 워크스페이스로 전환되며 새 탭으로 열립니다.

- 프로젝트 등록, 수정, 삭제 (삭제하면 해당 이슈도 모두 삭제)
- 이슈 등록과 상세 보기, 상태(할 일, 진행 중, 완료) 변경, 완료 이슈 제목 수정
- 이슈 설명에 이미지 붙여넣기 (`[Image #1]` 토큰), 정사각형 썸네일로 보이고 클릭하면 확대
- 이슈에 저장된 프로젝트·에이전트·실행 방식·작업 트리를 실행 창과 상세에서 변경 (완료 이슈는 잠금)
- 전체, 번호, 제목, 내용, 결과 조건을 골라 이슈 검색
- `할 일` 이슈의 ▶ 버튼(또는 전체 실행)으로 새 작업 트리 또는 기존 작업 트리에서 에이전트 실행
- 완료 이슈의 메모(자동 저장, 백업 포함)
- 완료 이슈의 에이전트 결과 전문 보관, 복사, 보기, 같은 작업 트리에서 이어서 작업(재개), 실행 이력
- 선택 모드로 여러 이슈 일괄 삭제와 상태 변경
- 백업(JSON 내려받기), 임포트(복구), 변경 때마다 자동 백업(기본 최근 10개)
- ⚙️ 설정: 자동 백업 켜기/끄기, 경로, 보관 개수(1~100). 저장을 눌러야 적용

## 데이터

- 프로젝트와 이슈: 플러그인 자체 저장소
- 에이전트 결과: 같은 저장소의 `result:<번호>-<생성시각>` 키 (값 하나 256KiB 한도 때문에 이슈와 따로 저장, 최대 80,000자)
- 첨부 이미지: `~/.orca-issues/images` (프로젝트를 삭제해도 파일은 남습니다)
- 결과 보기 파일: `~/Downloads/.orca/issue-tabs/*.issue-result` (custom editor로 열리고, 이 폴더는 Orca에 `issue-tabs` 폴더 워크스페이스로 등록됩니다)
- 자동 백업: 기본 `~/.orca-issues/backups`, 설정에서 변경 (이미지 파일은 포함하지 않고 파일명만 담깁니다)

## 권한

`trusted-worker`로 실행됩니다. 플러그인 API에 작업 트리 생성이 없어서 worker가 `orca` CLI를 호출하고, 이미지 파일을 저장합니다.

## 개발

```sh
orca plugin validate .
orca plugin dev watch .   # Orca에 불러와 로그와 리로드를 표시, Ctrl-C로 해제
```

## 테스트

```sh
orca plugin test .
orca plugin check .
```

Orca 1.4.247(Windows)에서는 플러그인 폴더가 Orca 설치 드라이브와 다르면 위 두 명령이 `cannot import "./orca-runtime.mjs"`로 실패합니다. 같은 드라이브(C:)에 복사해서 실행하세요.
